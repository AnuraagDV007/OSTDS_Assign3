# Regression & Clustering Algorithms in Python

This project demonstrates the implementation of various supervised and unsupervised learning algorithms using `scikit-learn`. The code includes:

## 🔍 Algorithms Covered

### Supervised Learning (Regression)
- Simple Linear Regression
- Multiple Linear Regression
- Polynomial Regression
- Ridge Regression
- Lasso Regression

### Unsupervised Learning
- Principal Component Analysis (PCA)
- K-Means Clustering
